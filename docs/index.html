yar2sig — YARA → Sigma Converter

Convert YARA rules into Sigma rules and native SIEM/EDR queries, with automatic IOC classification, MITRE ATT&CK tagging, and a professional web workbench.

View on GitHub Quick Start
ℹ️ This is a documentation page, not a live demo. The converter runs as a Flask API with sigma-cli and backend plugins bundled server-side, so it can't run as a static site. Spin it up with Docker in seconds — see below.

Features

IOC Classification

Auto-classifies patterns as URL, IP, hash, email, domain, registry, mutex, and more.

MITRE ATT&CK Tagging

Technique IDs in YARA meta (e.g. T1059.001) auto-convert to Sigma tags.

Configurable Pipelines

YAML mapping specs for sysmon, winsec, linux, and proxy log sources — extensible.

7 SIEM/EDR Backends

Elastic, Splunk, Microsoft Sentinel, QRadar, Carbon Black, SentinelOne, CrowdStrike.

Conversion Confidence

Every output includes a quality score, warnings, and review-required status.

Web Workbench + CLI

.yar import, pipeline/backend selection, and a full-featured CLI for batch conversion.

Run it locally

git clone https://github.com/wahidhendrawan/yara-sigma-webui.git
cd yara-sigma-webui
docker compose up -d --build
# open http://127.0.0.1:8000

Or locally with Python: pip install -r requirements.txt && python app.py (dev server on :5000).
